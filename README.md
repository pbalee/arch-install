# arch-install

Ez egy teljesen automatizált Arch Linux telepítő szkript fizikai hardverre, választható asztali környezettel. Egyetlen parancssoros indítással felépít egy teljes, használatra kész rendszert (XFCE Whisker menüvel, GNOME vagy KDE Plasma), grafikus kártya támogatással, VirtualBox-szal, távoli asztali eléréssel (RustDesk) és az egyedi beállításaid automatikus visszatöltésével.
